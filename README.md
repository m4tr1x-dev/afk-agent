# afk-agent

An AI agent that plays your games while you are away from the keyboard.

> Status: early work in progress — nothing here works yet.

## Idea

You leave the computer, the agent takes over. It watches the screen, decides what
to do, and drives mouse and keyboard so the grind keeps going without you.

## Planned scope

- Screen capture and game state recognition
- Decision loop (goal → plan → input)
- Mouse / keyboard input driver
- Per-game profiles and safety limits (stop conditions, time budget)

## Disclaimer

For personal use, single-player and offline scenarios. Automating online games
usually violates their terms of service — check before you use it.
