# How-to guides

A how-to guide assumes you know what you want and need the steps.
If you are trying to understand the system rather than operate it, read the [explanation](../explanation/index.md) pages instead.

Every guide follows the same shape: what must be true before you start, numbered steps, how to confirm it worked, and what to check when it did not.

## Planned guides

None of these exist yet — they describe software that has not been built.
The troubleshooting guides will carry most of the support load, and are written as soon as the subsystems they cover exist rather than at release.

### Getting it running

- Pick a model for your GPU
- Install model weights
- Select a capture target
- Run without the graphical shell

### When something is wrong

- Fix capture showing a black frame
- Fix input not reaching the game
- Review a session replay

### Tuning and control

- Write a long-horizon goal
- Configure safety limits
- Define a sensor
- Tune the tick budget
- Use multiple monitors
- Enable web research
